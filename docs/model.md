# 物理模型与计算约定

## 自由度与参考形状

沿螺旋材料中心线离散为短杆。每段具有位置、姿态、质量和转动惯量，连接允许弯曲和扭转，材料中心线不伸长。使用矩形截面时，截面两轴的二次面积矩不同，局部框架的连续性影响弯曲方向，必须与几何一起保存。

MuJoCo cable 的 `flat=false` 以模型编译时的螺旋姿态作为应力自由参考。悬挂或准备后的形状是受力状态，不能重新编译成新的无应力形状。整条彩虹圈的伸长来自杆的弯曲/扭转，不能用直接缩放渲染网格代替计算。

材料参数是 E、G（Pa），并由截面尺寸得到 EI、GJ。整体轴向等效刚度 k（N/m）是宏观输出/标定目标。仅给定一个 k，不能唯一确定所有截面、E、G 和预应力。

## 接触与场景

碰撞使用真实矩形杆段与台阶盒体。链上紧邻段的接触应过滤，跨圈的非相邻段必须能接触。接触点和碰撞盒的显示用于检查渲染外观与实际接触的一致性。

下落分为顶部约束下的准备阶段和解除约束后的自由运动。仿真时间零点是释放时刻，准备阶段不混入下落曲线。初始速度、准备残差和释放状态随结果保存。

楼梯场景包含有限宽度的台阶盒体，可指定初始位置、倾角和速度。释放后不使用脚本化轨迹、步态控制或自动复位来促使下楼。跨阶指标是数值运动分类，须结合动画和接触事件检查是否为翻转、滑动或侧落。

## 数值与能量

预览和精细档使用相同物理参数；网格与时间步长变化必须独立检查。较粗离散会改变有效刚度、接触形状和传播速度，不能自动视为同等精度。

内建动能由 MuJoCo 广义质量矩阵计算，重力势能由各杆质量和质心位置计算。插件将弹性力写入 `qfrc_passive`，而 `data.energy[0]` 不含该弹性能。用插件广义力与广义速度内积得到弹性功率，对每个积分步累积做功；阻尼及接触的功率分别累计。该积分含时间离散误差，需用步长收敛和功率平衡进行检查。

若后续添加显式弹性势能，须用姿态空间中的有限差分核对其梯度与插件力矩的一致性，才能将其加入总机械能。

所有输入输出采用 SI 单位；世界坐标 Z 向上，帧四元数按 w,x,y,z 传输。前端显示帧可以插值，研究指标由实际求解状态计算。

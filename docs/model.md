# 物理模型与计算约定

## 自由度与参考形状

沿螺旋材料中心线离散为短杆。每段具有位置、姿态、质量和转动惯量，连接允许弯曲和扭转，材料中心线不伸长。使用矩形截面时，截面两轴的二次面积矩不同，局部框架的连续性影响弯曲方向，必须与几何一起保存。

MuJoCo cable 的 `flat=false` 以模型编译时的螺旋姿态作为应力自由参考。悬挂或准备后的形状是受力状态，不能重新编译成新的无应力形状。整条彩虹圈的伸长来自杆的弯曲/扭转，不能用直接缩放渲染网格代替计算。

材料参数是 E、G（Pa），并由截面尺寸得到 EI、GJ。整体轴向等效刚度 k（N/m）是宏观输出/标定目标。仅给定一个 k，不能唯一确定所有截面、E、G 和预应力。

## 接触与场景

碰撞使用真实矩形杆段与台阶盒体。链上紧邻段的接触应过滤，跨圈的非相邻段必须能接触。接触点和碰撞盒的显示用于检查渲染外观与实际接触的一致性。

下落分为顶部约束下的准备阶段和解除约束后的自由运动。仿真时间零点是释放时刻，准备阶段不混入下落曲线。初始速度、准备残差和释放状态随结果保存。

准备首先求解原生静态广义力平衡：`mj_passive` 给出插件力，`mj_rne` 给出重力项，保持根端平移受约束，求各旋转自由度的平衡。完整 `mj_forward` 再校核归一化 `M*qacc` 残差、锚点偏移及接触。含接触的状态采用动力学松弛回退。解析伸长螺旋只用于初值，不修改无载参考形状或模型刚度。未收敛状态会明确记录，不能作为悬挂平衡验证结果。

楼梯场景包含有限宽度的台阶盒体，可指定初始位置、倾角和速度。释放后不使用脚本化轨迹、步态控制或自动复位来促使下楼。跨阶指标是数值运动分类，须结合动画和接触事件检查是否为翻转、滑动或侧落。

v4增加 `initial_pose=arched` 的手动跨阶拱形初态。首端若干完整压缩圈贴近上阶，自由端的完整压缩圈位于下阶上方；`arch_free_clearance` 指自由端碰撞几何与下阶踏面的实际间隙。中部围绕平面拱轴生成螺旋并解固定杆长约束，然后只写入运行时 `data.qpos`。编译时 `model.qpos0`、无载螺旋及插件参考曲率保持不变。因此初态包含弯曲、扭转储能，标为 `manual_non_equilibrium`，不冒充静态平衡。释放后没有持续约束、执行器或施加的驱动力。

拱形初态随记录输出目标/实际节点、杆长与端点误差、无载形状保持检查、完整端圈踏面范围、初始接触穿透和弹性能近似。无法放入完整端圈或固定杆长解失败时报告错误。`tilted` 保留原有整体倾斜初态；旧配置未包含新字段时默认采用它，原有下落与零角速度楼梯数据的物理定义保持一致。

用户提供的楼梯视频仅用来识别手动弯曲起步、端圈交替支撑、中部拱起与收拢这些定性现象。视频没有尺度标记，播放时间也未标定；12圈和36圈拱形预设的圈数、尺寸、质量、材料和摩擦都是明确假设。预设之间的圈数差异是两个物理模型；对同一预设选择预览/精细档只调整离散与积分设置。原视频及提取画面不随项目发布。

v3把初始角速度明确为世界+Y轴；MuJoCo自由关节使用局部角速度，所以必须转换到首杆的材料框架。v2的非零扰动会混入侧向与偏航转动，早期楼梯失败探针只作为诊断保留。角速度为零的下落基准不受该修正影响，v2的下落验证数据可以对照复现。圈间摩擦与台阶/地面摩擦分开设置，避免把光滑圈面和粗糙踏面视为同一个接触对。

当前接触为 `condim=3`，只启用法向与两个滑动方向。MuJoCo friction 的 spin/roll 两项是长度系数，当前没有启用它们；本模型不将无量纲滑动摩擦当作滚动阻力标定。若扩展到 `condim=4/6`，需另设并标定有长度单位的参数。楼梯索引0是起始顶踏面，索引1是第一个下降踏面，支撑交替记录器只统计下降踏面。

首次接触阶序与持续端圈支撑分开报告。端部区为完整一圈；踏面法向力须连续 20 ms 达到总重力的 10%，并按连续阶索引、首次支撑端部交替判定。中部先形成支撑会标记歧义；后端随后收拢到同一阶是正常收缩阶段，不倒改首着地端部。数值记录器的“确认翻转”仍需通过网格加密和回放检查，不能直接当作实验支持。

## 数值与能量

预览和精细档使用相同物理参数；网格与时间步长变化必须独立检查。较粗离散会改变有效刚度、接触形状和传播速度，不能自动视为同等精度。

内建动能由 MuJoCo 广义质量矩阵计算，重力势能由各杆质量和质心位置计算。插件将弹性力写入 `qfrc_passive`，而 `data.energy[0]` 不含该弹性能。用插件广义力与广义速度内积得到弹性功率，对每个积分步累积做功；阻尼及接触的功率分别累计。该积分含时间离散误差，需用步长收敛和功率平衡进行检查。

平台另外核算矩形截面的 Saint-Venant 扭转常数及两轴弯曲二次矩，重建弹性能估计。8段/圈的小角度梯度检查与插件力矩仍有约11%偏差，因此保持为独立近似诊断，不将其当作精确守恒势能。机械功率平衡比较动能与重力势能变化对弹性、阻尼及接触做功；已经计入弹性做功时不能再重复把弹性势能变化加到该等式中。

所有输入输出采用 SI 单位；世界坐标 Z 向上，帧四元数按 w,x,y,z 传输。前端显示帧可以插值，研究指标由实际求解状态计算。

# 验证与验收

本文件定义验证口径。实际运行结果保存在 `docs/validation-results.json`（生成后随发布提交），执行日志保存在 CI artifacts。没有执行的检查标记为未验证；不能将测试框架通过等同于真实物理模型已获得实验支持。

## 分层检查

1. 几何与质量：螺旋圈数、截面坐标框架、总质量、参考态弹性力及跨圈接触。
2. 自由落体：释放后、接触地面前，对比质心 `z0 + vz0*t - g*t²/2`；归一化误差目标不超过 1%。
3. 悬挂平衡：报告末段速度、约束残差和长度。文献预设的静态长度误差目标 5%；使用该目标标定时将其标为拟合检查。
4. 收敛：保持物理参数不变，分别减半时间步长与加密杆段；比较下端启动、收缩时间和连续曲线。下落关键时间指标变化目标不超过 5%。
5. 楼梯：至少一个预设产生三次连续的被动跨阶；通过轨迹和接触确认运动类型，并检查加密后事件序列的稳定性。停止、滑移、侧落也属于应记录的结果。
6. 功率平衡：累计弹性、阻尼、接触与外部做功，检查动能和重力势能变化的数值残差；这不是包含摩擦场景的机械能守恒断言。
7. 软件：任务状态、暂停/单步/取消、扫描组合、导入导出、重启标记、浏览器回放和容器持久化。

## 报告原则

- 数值测试结果、文献拟合结果、独立实验支持分别记录。
- 非有限状态、积分器警告、超时或未收敛的准备过程必须在结果中可见。
- 未能检测到一个物理事件时返回空值与原因，不把末帧时间冒充事件时刻。
- 相图应显示失败/中断格点，不能只显示成功计算。
- 发布镜像标签仅指软件版本；每个物理预设另有验证状态。

# 验证与验收

本文件定义验证口径。实际运行结果保存在 `docs/validation-results.json`（生成后随发布提交），执行日志保存在 CI artifacts。没有执行的检查标记为未验证；不能将测试框架通过等同于真实物理模型已获得实验支持。

当前已完成的3圈下落小算例：减半时间步长后启动/收缩时间变化约0.081%/0.014%；16→32段/圈变化4.52%/0.596%，符合5%目标。32段时质心轨迹最大误差0.0424mm（0.18s窗口），最大接触穿透1.143mm，计算耗时约255秒。圈间接触的软化及能量近似仍需随研究问题检查。此小算例不能代表所有参数组合。

39圈文献预设的静态长度拟合偏差约0.231%；该长度参与了拟合，独立实验支持尚未建立。模型v3的世界角速度修正已重跑下落检查，v4新增可选拱形初态。楼梯停止、滑移与侧落的实际配置和原生支撑记录保存在 `docs/validation/`；三次稳定翻转仍未确认，完整验收和 `latest` 推广保持未通过。

楼梯三阶基准已在8段/圈、50µs步长下观察到连续端圈支撑“末端→首端→末端”，最大穿透0.547mm；没有初始角速度或运行时驱动，只有明确记录的初始前向速度0.05m/s。Linux扩展检查中，减半步长仍得到相同前三端序，但第二支撑时刻变化6.495%，超过既定5%标准；16段/圈在3600秒限时内仅算到0.8025875秒。没有原生警告，网格收敛仍未建立。详见 `docs/validation/stairs-convergence.json`；超时本身不证明动力学不稳定。

v4的12圈/36圈拱形初态均通过固定杆长、端圈踏面范围、参考形状保持与无初始自交检查。12圈0.12秒释放没有警告；其完整1.5秒运行实际为滑移，仅有1个交替支撑候选，不能称为三阶复现。使用假设钢类模量/密度的薄片探针在0.0542秒附近发生 BADQACC，作为失败记录保留，未加入默认预设。MuJoCo报警会自动重置内部时钟，失败后的即时状态不用于物理分析，最后真实导出帧为0.04秒。详见 `arched-initial-pose.json`、`arched-full-release.json`、`thin-steel-probe-failed.json`。

复算命令为 `python scripts/validate_stairs.py --output reports/stairs-validation`，也可手动运行 `Stair walking research validation` 工作流的 extended 模式。三档分别为8段/圈与50µs、8段/圈与25µs、16段/圈与12.5µs，保持材料、台阶和初态相同。要求三例均无警告、完成2.4秒、前三阶持续端圈支撑序列一致；额外采用各支撑时刻相对变化不超过5%的保守数值标准。这一楼梯时间标准不是实验误差。quick模式只重跑基准，不评估收敛。

## 分层检查

1. 几何与质量：螺旋圈数、截面坐标框架、总质量、参考态弹性力及跨圈接触。
2. 自由落体：释放后、接触地面前，对比质心 `z0 + vz0*t - g*t²/2`；归一化误差目标不超过 1%。
3. 悬挂平衡：报告末段速度、约束残差和长度。文献预设的静态长度误差目标 5%；使用该目标标定时将其标为拟合检查。
4. 收敛：保持物理参数不变，分别减半时间步长与加密杆段；比较下端启动、收缩时间和连续曲线。下落关键时间指标变化目标不超过 5%。
5. 楼梯：至少一个预设产生三次连续的被动跨阶；通过轨迹和接触确认运动类型，并检查加密后事件序列的稳定性。停止、滑移、侧落也属于应记录的结果。
6. 功率平衡：累计弹性、阻尼、接触与外部做功，检查动能和重力势能变化的数值残差；这不是包含摩擦场景的机械能守恒断言。
7. 软件：任务状态、暂停/单步/取消、扫描组合、导入导出、重启标记、浏览器回放和容器持久化。

## 报告原则

- 数值测试结果、文献拟合结果、独立实验支持分别记录。
- 非有限状态、积分器警告、超时或未收敛的准备过程必须在结果中可见。
- 未能检测到一个物理事件时返回空值与原因，不把末帧时间冒充事件时刻。
- 相图应显示失败/中断格点，不能只显示成功计算。
- 发布镜像标签仅指软件版本；每个物理预设另有验证状态。
